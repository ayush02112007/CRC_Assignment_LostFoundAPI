# College Lost & Found API

A FastAPI REST API for managing lost and found items in a college campus.

## Technologies Used

- Python
- FastAPI
- SQLModel
- Pydantic
- SQLite
- Uvicorn

## Features

- Create a lost/found item
- View all items
- View item by ID
- Update an item
- Delete an item
- Filter items by status
- Filter items by category
- Input validation
- 404 error handling
